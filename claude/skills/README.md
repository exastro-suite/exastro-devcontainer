# はじめに
- 本ディレクトリにはClaudeのskillを格納します
- 個人用のskillを登録したい場合は`private-`,`temp-`,`work-`,`test-`のプレフィックスで作成ください

# skillの説明
- Claudeのskillはs`/` + スキル名で起動できます
- skillの一覧
    | skill名 | 説明 |
    | ------- | ---- |
    | **mcp-***** | mcp関連のskill |
    | mcp-publish-manual | ExastroのマニュアルGitレポジトリのドキュメントから、要約し、RAG用の日本語・英語のドキュメントを作成し、Qdrant登録します |
    | mcp-publish-menu-reference | menuの日本語ドキュメントから英語のドキュメントを作成し、Qdrant登録します |
    | mcp-publish-openapi | OpenAPIの日本語ドキュメントから英語のドキュメントを作成し、Qdrant登録します |
    | mcp-publish-playbook-reference | Exastroに登録済みのPlaybookと日本語版の追加ドキュメントから、RAG用の英語のドキュメントを作成し、Qdrant登録します |
    | mcp-tool-create | 指定したAPIのOpenAPIからtoolのひな型を作成します |
